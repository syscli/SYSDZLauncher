# SYSDZ Launcher

A DayZ server launcher for Windows, made by SYSCLI.

- Find servers fast, without the fake servers and server farms that fill the
  Steam list.
- See before you join which mods a server needs and which of yours need an
  update, then join with every mod ready.
- Join when a full server has room, or when an offline one comes back.
- Keep the mods of your favorite servers up to date in the background.
- Load your own local mods for testing.
- Show the server you play on in Discord, with a Join button for friends.

## Download

**[Download SYSDZ Launcher 1.0.1 for Windows](https://github.com/syscli/SYSDZLauncher/releases/download/v1.0.1/SYSDZ-Launcher-Setup-1.0.1.exe)**

Run the installer. It needs no admin rights and installs for your Windows
user only. If Windows shows "Windows protected your PC", press **More info**,
then **Run anyway**. The launcher updates itself after that.

Website: https://dayz.syscl.ru

## Requirements

- Windows 10 or 11, 64-bit
- Steam, signed in to an account that owns DayZ
